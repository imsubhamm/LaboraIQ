# OQ-001 — Operational qualification template

Execute approved synthetic cases for authentication expiry, 401/403 behavior,
permission matrix, organization and branch CRUD, tenant/branch isolation, duplicate
constraints, assignment effective/expiry behavior, audit capture/masking/immutability,
pagination/filtering, request correlation, failure handling, migration rollback
policy, SQS retry/DLQ, backup restore, and monitoring alerts.

Record preconditions, exact test data, expected/actual results, logs or screenshots,
deviations, corrective action, retest, executor and independent reviewer.
